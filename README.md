# 工时统计系统

一个基于前端单页的工时管理工具，核心围绕三类数据运行：
- 记录数据（实际工时记录，唯一事实来源）
- 模板数据（周模板基线，用于差异对比与批量写入）
- 识别框架（排班表识别与模板生成能力）

当前线上入口：`index.html`（GitHub Pages）。

## 1. 系统核心设计

### 1.1 数据分层

1. 记录数据（Records）
- 存储每日、每人、每类型的实际记录条目。
- 每条记录包含绝对定位字段（如 `absSlotKey`、`absRow`、`absCol`）和相对可读信息（`rowLimit`、`colLimit`）。
- 业务计算（按天/按周工时、导出统计）以记录数据为准。

2. 模板数据（Template）
- 包含模板统计结构（`data`）和原始视图结构（`preview`）。
- 模板本身不等于当前周记录，默认不直接改写记录数据。
- 用于：
  - 差异视图基线
  - 周修订槽位定位
  - 显式“写入模板数据”操作

3. 识别框架（Schedule Parser）
- 将排班 Excel 解析为模板。
- 由“姓名映射、类型关键词、星期关键词、忽略词”等规则驱动。
- 输出可复用模板，并保留原始网格供周修订与原始视图查看。

### 1.2 关键原则

- 模板数据与记录数据隔离：
  - `替换当前模板` 只切换模板基线，不修改记录。
  - `写入模板数据` 才会改记录。
- 周修订按绝对定位映射：
  - 实际操作以 `absSlotKey / absRow / absCol` 为主。
  - 相对坐标（行限位/列限位）仅用于显示理解。

## 2. 用户操作流程（推荐）

1. 维护人员与工时类型
- 在“人员”“工时类型”中先完成基础配置。

2. 生成或选择模板
- 使用“排班转模板”导入排班表并保存模板，或从模板库选择已有模板。

3. 指派当前周模板
- 点击“替换当前模板”：仅替换本周模板基线并可开启差异视图。

4. 周修订（按绝对槽位）
- 切换到“按周 -> 修订”。
- 在原始视图中进行点位操作（删除/替换）。
- 修订会落到记录数据，并保持槽位映射。

5. 按天核对
- 回到“按天”检查卡片明细（行限位/类型/移动/删除）。

6. 导出
- 在导出预览中确认按天/按周/修订视图后导出 Excel。

## 3. 主要功能说明

### 3.1 按天视图
- 显示每人每类型记录卡片。
- 卡片支持删除、移动到其他人员。
- 差异模式下可看到“新增/移出”条目。

### 3.2 按周视图
- 统计模式：按周汇总每人每日工时。
- 修订模式：基于模板原始网格进行槽位级替换。

### 3.3 模板管理
- 模板库支持新增、删除、指派。
- 模板查看为原始视图（raw grid），用于核对槽位布局。

### 3.4 排班转模板
- 三阶段：上传 -> 规则校准 -> 原始视图确认并保存。
- 生成模板同时保留 `preview.rawGrid / rawMerges / cellSlotMap`。

### 3.5 导出
- 支持按天汇总、按周汇总、修订视图格式导出。
- 奖励工时只影响本次导出结果，不回写日常记录。

## 4. 数据持久化

本系统使用浏览器 `localStorage` 持久化，常见键包括：
- `wh_personnel`
- `wh_types`
- `wh_records`
- `wh_template_library`
- `wh_week_template_map`
- `wh_week_day_locks`
- `wh_schedule_rules`
- `wh_hidden`
- `wh_autohide`
- `wh_theme`

## 5. 开发说明

### 5.1 技术栈
- React 18（UMD）
- Babel Standalone
- SheetJS (`xlsx`)
- `pinyin-pro`

### 5.2 目录结构
- `index.html`：主入口与组件
- `assets/js/core.js`：工具函数与解析逻辑
- `assets/css/styles.css`：样式
- `index_test.html`：测试/实验入口（保留）

### 5.3 本地运行

可直接双击 `index.html`，或使用静态服务：

```powershell
python -m http.server 8080
```

访问：<http://localhost:8080>

## 6. 版本迁移提示

如果你是旧版本用户，请注意：
- “模板 = 基线”已替代“模板直接代表当前周记录”的旧理解。
- 周修订点击操作已按绝对位置映射，避免同类行限位联动误改。
- 查看模板以原始视图为主，统计视图仅用于汇总理解。

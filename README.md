# 工时统计系统

一个用于值班、排班和工时汇总的前端单页工具，支持：

- 人员管理
- 工时类型管理
- 按天录入
- 按周统计
- 按周修订
- 模板导入 / 套用
- 排班表转模板
- Excel 导入导出
- 本地 `localStorage` 持久化

项目入口为 `index.html`，启用 GitHub Pages 后可直接访问。

## GitHub Pages

- 仓库页地址：`https://<你的 GitHub 用户名>.github.io/<仓库名>/`
- GitHub Pages 默认读取仓库根目录下的 `index.html`
- 如果你希望使用根域名形式访问，需要把仓库名改成 `<用户名>.github.io`

## 用户手册

### 推荐流程

1. 维护人员名单
2. 校准工时类型
3. 用“排班转模板”整理周模板
4. 切到“按周 - 修订模式”套用模板并替换人员
5. 切回“按天”逐格核对统计差异
6. 最后导出 Excel

### 核心界面

- 顶部工具栏：切换按天 / 按周、日期导航、导入记录、导入模板、排班转模板、导出
- 左侧边栏：人员搜索、隐藏零工时、人员列表、模板状态
- 主区域：按天统计、按周统计、按周修订
- 弹窗区：工时类型、人员、导出、模板预览、排班转模板

### 按周模式

按周模式分为两种子模式：

- `统计`：查看本周各人员每日工时和周合计
- `修订`：按模板附带的原始 Excel 视图修订当前周排班

#### 修订模式说明

- 左侧直接显示与原 Excel 一致的原始视图
- 第 1 下点击某个已识别姓名，会删除该槽位对应的 1 次工时
- 第 2 下点击同一个槽位，会把它选中为待替换状态
- 在右侧选择新人员后，可以把新名字补入该槽位
- 第 3 下点击同一个已选槽位，会恢复模板原数据
- 打开“显示差异”后：
  - 黑边表示这个槽位相对模板发生了新增或替换
  - 红色空槽表示模板里原本有，但当前周已经被删掉

推荐用法：

1. 先在按周视图切到 `修订`
2. 应用模板
3. 在原始视图周修订里完成人员替换
4. 再切到按天逐格核对

### 排班转模板

`排班转模板` 分三步：

1. 上传 Excel
2. 规则与映射
3. 编辑与确认

支持的规则：

- 姓名映射规则：把别名映射到系统人员
- 类型关键词规则：命中关键词后强制归类工时类型
- 星期关键词规则：处理非标准周几写法
- 忽略关键词规则：忽略不应该识别成人员的文本

第三步会显示：

- 与原 Excel 布局一致的可视化预览
- 人员 × 星期的编辑表

建议先把模板编辑干净，再保存供后续按周修订使用。

### 模板导入与套用

支持两类模板来源：

- 从排班表识别并保存的周模板
- 从系统导出的工时明细中导入的模板

套用规则：

- 按周视图：覆盖当前整周
- 按天视图：只覆盖当前日期对应的周几

注意：模板套用会替换当前目标范围内已有记录。

### 显示差异

导入模板后可以打开“显示差异”：

- 按天：显示当前计数与模板计数的差值
- 按周统计：显示当前小时数与模板小时数的差值
- 按周修订：用黑边和红色空槽显示替换情况

### 导出预览与奖励工时

导出前会先进入预览页，可切换：

- `按天预览`
- `按周预览`

预览页会显示每列工时，并在总计前新增 `奖励工时` 列，允许手动录入本次导出的奖励工时。奖励工时不会写回日常记录，只影响这次导出的统计表。

导出会生成：

- `小时统计(按日)`
- `小时统计(按周)`
- `工时明细`

其中 `工时明细` 可以再次导回系统恢复记录。

### 数据保存

系统不依赖后端，所有数据默认保存在浏览器本地：

- 人员名单
- 工时类型
- 记录数据
- 隐藏状态
- 主题配置
- 排班规则库

## 开发者手册

### 技术栈

- `React 18 UMD`
- `ReactDOM 18`
- `Babel Standalone`
- `SheetJS xlsx`
- `pinyin-pro`
- `localStorage`

### 目录结构

- `index.html`：页面入口、主要 React 组件
- `assets/css/styles.css`：全局样式
- `assets/js/core.js`：工具函数、排班解析逻辑
- `.bak/`：本地备份目录（已在 `.gitignore` 中忽略）

### 当前数据模型

主要本地存储键：

- `wh_personnel`
- `wh_types`
- `wh_records`
- `wh_hidden`
- `wh_autohide`
- `wh_theme`
- `wh_schedule_rules`
- `wh_flow_collapsed`

记录结构按日期存储，再向下按人员和工时类型计数。

通过“排班转模板”保存的模板还会额外携带：

- 原始视图网格
- 合并单元格信息
- 已识别槽位映射

这部分数据专门用于按周修订模式。

### 主要组件

- `App`：应用状态、导入导出、模板套用
- `DayView`：按天录入与核对
- `WeekView`：按周统计 / 按周修订
- `WorkflowPanel`：操作流程面板
- `ScheduleImportModal`：排班表转模板
- `TemplateViewModal`：模板预览
- `CalendarPicker`：日期与周切换
- `ExportModal`：导出预览与奖励工时录入

### 运行方式

直接打开 `index.html` 即可。

如需本地静态服务：

```powershell
python -m http.server 8080
```

然后访问 [http://localhost:8080](http://localhost:8080)。
